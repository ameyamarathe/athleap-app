▎ Relationship Summary
app schema
users → user_fitness_profiles (1:1)
users → user_schedule_preferences (1:7)
users → user_watch_connections (1:many)
users → training_plans (1:many)
training_plans → planned_sessions (1:many)
planned_sessions → planned_intervals (1:many)
planned_sessions → planned_sessions (self-ref: modified from)
users → completed_workouts (1:many)
completed_workouts → workout_strength_sets (1:many)
exercises → workout_strength_sets (1:many)
users → daily_metrics (1:many — one per day)
users → coach_threads → coach_messages (1:many:many)
raw schema
users → raw.daily_vitals (1:many)
users → raw.sleep_sessions (1:many)
users → raw.activities (1:many)
raw.activities → completed_workouts (1:1 after match)

audit schema
users → audit.ai_plan_adjustments (1:many)
planned_sessions → audit.ai_plan_adjustments (1:many)
training_plans → audit.ai_plan_adjustments (1:many)
Data Flow
APIs → raw.* → dbt staging
dbt staging → dbt intermediate
dbt intermediate → dbt marts
dbt marts → app.daily_metrics
app.daily_metrics → FastAPI → iOS

App never queries raw.* directly.
daily_metrics = pre-computed read layer.
